# Quiz Levels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a level present a question with options instead of demanding a code found in a city — so the engine can run games that need no field and no code entry.

**Architecture:** A new `Option` table hanging off `Question`. A question is a quiz question **iff it has options**; there is no mode flag to disagree with reality. With `options` empty every existing code path runs unchanged, so the frozen 234-scenario suite becomes a guarantee rather than a hazard.

**Tech Stack:** Ruby 3.3.12, Rails 8.0.5.1, SQLite (dev/test), PostgreSQL (production), RSpec 3.13.

## Global Constraints

- Ruby is pinned to `3.3.12` and Rails to `8.0.5.1`. Do not change either.
- rbenv is not on PATH in non-login shells. Prefix every Ruby command with `export PATH="$HOME/.rbenv/bin:$HOME/.rbenv/shims:$PATH"`.
- **Never create, edit or delete any file under `features/`.** Those `.feature` files are the frozen contract the Merb→Rails port was validated against.
- Existing gates must stay green: `bundle exec rspec` is **665 examples, 0 failures, 6 pending**; `bundle exec cucumber` is **234 scenarios (2 pre-existing "undefined" placeholders), 2362 steps**. `bin/rails zeitwerk:check` must print `All is good!`.
- **A level with no options must behave exactly as it does today**, through exactly the same code. Every new branch is guarded by "does this level have options".
- **A question is a quiz question iff it has options.** No type column, no mode flag.
- **Correctness is set equality** — every correct option selected and no incorrect one. No partial credit; this product ranks by elapsed time and has no score.
- **Every wrong submission is charged, including a repeat of one already tried.** Do not track burned combinations.
- **The penalty must never touch `current_level_entered_at`.** That column is the sole input to every hint countdown; moving it would bring the next hint *closer* on a wrong answer.
- **Platform chrome goes through `t()`; author-written content renders verbatim.** New keys go in all four of `config/locales/{ru,en,uk,ka}.yml`. `spec/i18n_spec.rb` enforces `ru`↔`en` exact parity and `uk`/`ka` as a subset; `raise_on_missing_translations` is on in test. All four files are currently complete — supply real Ukrainian and Georgian, not Russian placeholders.
- Factories are plain helpers in `spec/spec_helpers/fixtures_helper.rb`. No FactoryBot. `create_user` takes **no arguments**. New specs use `expect`.
- Hash rockets (`:key => value`) are the surrounding style in these models and controllers.
- **Out of scope:** points or partial credit; option shuffling; any change to code matching; media in options; question banks; per-question time limits; any game-wide quiz flag.

### Facts verified against this app while writing this plan

Do not re-derive these; do check anything this plan does *not* state.

- `Question` already means "one thing that must be answered"; `Answer` means "an accepted spelling of the correct code", and **every `Answer` row is correct by construction**. `Question#matches_any_answer` compares `strip.upcase` on both sides.
- `Level has_many :questions`; `GamePassing#all_questions_answered?` is what advances a level. A level needing several codes already works this way — quiz questions inherit it for free.
- `GamePassing#check_answer!(answer)` takes a **string**. Do not modify it; quiz answering gets its own entry point.
- `Game#place_of` counts `GamePassing.of_game(self).finished_before(game_passing.finished_at).count`, where `finished_before` is `where('finished_at < ?', time)`.
- `Game#translatable_records` walks `self.levels.includes(:content_translations, :hints => :content_translations, :questions => :content_translations)`. The nesting is deliberate — a sibling `includes` leaves each hint and question to lazy-load, one query per record. **This project has shipped that N+1 twice.**
- `Game#label_for(record, field)` is a `case` over `Game` / `Level` / `Hint` / `Question`, returning an `I18n.t` string. A record type with no branch returns `nil`.
- `TranslatableContent` requires the including model to define `#translation_game` and a `TRANSLATABLE_FIELDS` constant.
- **`Question::TRANSLATABLE_FIELDS` is deliberately `[].freeze`** — the `questions` column is vestigial. Do not add to it.
- Answers are authored on their own page: `answers#index` renders the list, a delete link per row, and an add form. **Options follow that pattern**; levels have no shared `_form` partial (`new` and `edit` each carry their own).
- `app/views/levels/edit.html.erb` shows the translation pattern: `shared/language_tabs` plus a per-field branch on `active_locale == game.primary_locale`, writing to `record[translations][locale][field]`.
- `create_level(:game => g)`, `create_question(:level => l)`, `create_game_passing(:level => l)` exist. `create_game_passing` derives its game from the level and makes its own team.

- [ ] **Step 4: Write the model**

```ruby
# app/models/option.rb
#
# One choice presented for a quiz question.
#
# Deliberately not an Answer. Answer means "an accepted spelling of the correct
# code" and every row is correct by construction; a row representing a
# deliberately wrong choice would contradict that everywhere, and would put
# distractors in the very table the code-matching path reads. A separate table
# means that path cannot change behaviour at all.
class Option < ApplicationRecord
  include TranslatableContent

  TRANSLATABLE_FIELDS = %w[text].freeze

  belongs_to :question, optional: true

  validates :text, presence: true

  scope :correct, -> { where(:is_correct => true) }

  # Options are author-written content, so a multilingual game must translate
  # them before publication -- see Game#translatable_records.
  def translation_game
    self.question&.level&.game
  end
end
```

- [ ] **Step 5: Write `answer_options!`**

In `app/models/game_passing.rb`, beside `check_answer!` — **do not modify `check_answer!` itself**:

```ruby
  # The quiz counterpart of check_answer!, which takes a typed string and is
  # left completely untouched. Returns true when the selection is exactly right.
  #
  # Set equality, not overlap: every correct option and no incorrect one.
  # Partial credit was considered and rejected -- this product ranks teams by
  # elapsed time and has no concept of a score, so "partly right" has nowhere
  # to go.
  def answer_options!(question, option_ids)
    chosen = Array(option_ids).map(&:to_i).uniq.sort

    if chosen == question.correct_option_ids && chosen.any?
      pass_question!(question)
      pass_level! if all_questions_answered?
      true
    else
      # Charged on every wrong submission, including a repeat of one already
      # tried: forgiving repeats would let a team walk the option space for the
      # price of a single mistake.
      #
      # update_column, and NOT touching current_level_entered_at: the penalty
      # must never reach the hint clock.
      update_column(:penalty_seconds, penalty_seconds + question.level.wrong_answer_penalty)
      false
    end
  end
```

- [ ] **Step 3: Add `effective_finished_at`**

In `app/models/game_passing.rb`:

```ruby
  # What ranking compares. For every game that predates quiz levels
  # penalty_seconds is 0, so this is finished_at unchanged.
  def effective_finished_at
    return nil unless self.finished_at

    self.finished_at + self.penalty_seconds.to_i
  end
```

- [ ] **Step 4: Rank on it**

Replace `Game#place_of`:

```ruby
  # Compared in Ruby rather than SQL. Ranking now needs finished_at +
  # penalty_seconds, and expressing that as a portable interval across SQLite
  # and PostgreSQL is more trouble than it is worth for a listing of tens of
  # teams. The old finished_before scope stays for its other callers.
  def place_of(team)
    game_passing = GamePassing.of(team, self)
    return nil unless game_passing and game_passing.finished?

    mine = game_passing.effective_finished_at
    earlier = GamePassing.of_game(self).finished.count do |other|
      other.effective_finished_at < mine
    end
    earlier + 1
  end
```
